# 公众号素材优先写作流程设计

## 目标

将公众号写作页从“依次填写标题、形象、主题、读者、语气、素材，再进入单独确认步骤”改为“先确定写作来源，自动形成写作简报，在同一页直接生成文章”。素材是可选输入；没有素材时仍可从一句话想法开始。

本次只重构文章创建前的流程。文章编辑、排版预览、提示词、正文配图、封面、草稿同步和发布保持现有行为。

## 当前问题

- 素材选择埋在表单中间，用户需要先填写标题和主题，无法自然地从资料库开始写作。
- 标题和主题被前端强制要求，但正文模型本身已经会生成标题，存在重复输入。
- “输入主题/素材”和“生成文章”是两个页面步骤，第二步只重复展示输入并增加一次点击。
- 当前文章生成结果可能不保留用户给出的标题，前端却按输入标题轮询恢复，超时恢复不可靠。

## 统一入口

写作页第一步改为 `选择素材与写作要求`，顶部首先显示资料库选择器，并支持两种来源：

### 有素材

1. 用户打开置顶的素材选择器，选择一个或多个资料库条目。
2. 用户点击 `使用选中素材（N）` 关闭选择器，页面自动请求一次写作简报。
3. 简报根据素材标题、正文、来源、备注和用户补充要求生成。

资料列表继续显示 `未使用` 或 `已写过 N 篇`，支持搜索和多选。已使用素材可以再次选择，不做硬限制。勾选过程不触发模型，只有确认整组选择后才调用一次，避免多选时重复计费。

### 无素材

1. 用户不选择资料，直接在 `一句话想法或写作要求` 中输入内容。
2. 点击 `智能补全写作简报`。
3. 系统根据该输入生成同样的写作简报。

有素材时补充要求可为空；没有素材时补充要求必填。两者至少满足一个，才允许调用写作简报或生成正文。

## 写作简报

写作简报在第一步内联显示，不增加新的流程步骤，包含以下可编辑字段：

- `文章标题`
- `文章主题与核心观点`
- `目标读者`
- `语气风格`
- `插画形象`

素材选择确认后自动生成一次简报。无素材流程通过按钮触发，避免在用户仍在输入时重复消耗额度。素材集合或补充要求发生变化后，页面显示 `写作来源已变化，建议重新整理`，但不覆盖用户已经编辑的简报；只有用户明确点击重新整理才覆盖。

简报生成成功后，主按钮为 `生成文章`。原“2. 生成文章”独立页面删除；生成进度、错误和恢复提示直接显示在当前卡片内。

## 接口与数据流

新增接口：

`POST /api/platforms/wechat-mp/articles/writing-brief`

请求：

```json
{
  "material_ids": [1, 2],
  "idea": "希望写成面向项目经理的考点复习文章"
}
```

响应：

```json
{
  "title": "项目范围管理：高频考点与易错关系",
  "topic": "围绕范围管理流程、WBS、确认范围与质量控制的区别展开",
  "target_reader": "备考信息系统项目管理师的读者",
  "tone": "清晰、紧凑、适合复习",
  "cost_estimate": {
    "currency": "CNY",
    "total_yuan": "0.0000",
    "calls": 1
  }
}
```

服务端必须按当前用户加载素材，保持用户隔离；缺失、已删除或不属于当前用户的素材统一返回 404。简报模型调用记录 `UsageRecord`，`platform="wechat_mp"`、`step="prepare_writing_brief"`，用于账单中心统计。

正文创建继续调用现有 `POST /api/platforms/wechat-mp/articles`。请求中的标题和主题改为来自可编辑简报。正文模型输入增加 `title_hint`，并要求返回标题与已确认标题一致，从而使现有按标题恢复逻辑可靠。素材与文章的关联、素材使用状态和正文调用费用继续走现有实现。

## 前端流程状态

文章创建前使用以下状态，不写入数据库：

- `source_empty`：未选择素材且未输入想法。
- `source_ready`：已选择素材或已输入想法，尚未生成简报。
- `brief_loading`：正在生成简报。
- `brief_ready`：简报可编辑，可以生成文章。
- `brief_stale`：来源变化，保留当前简报并提示重新整理。
- `article_loading`：正文生成中。

打开已有文章时继续直接进入现有编辑或配图步骤，不经过素材选择和写作简报。

## 页面结构

第一步从上到下排列：

1. `选择资料库素材（可选）`：置顶，以选择器承载搜索、多选、使用状态和整组选中确认。
2. `一句话想法或补充要求`：无素材时必填，有素材时用于限定角度。
3. 写作简报区域：标题、主题、目标读者、语气、形象。
4. 费用说明和主操作按钮。

当资料库为空时，显示 `暂无资料，也可以直接输入想法开始写作`，并提供前往资料库的次要入口。无论是否有素材，都不阻断写作。

顶部流程由六步缩减为五步：

1. 选择素材与写作要求
2. 编辑与预览
3. 生成提示词
4. 编辑提示词并生图
5. 同步草稿/发布

## 错误与恢复

- 简报生成失败：保留素材选择和想法，展开空白可编辑字段，并提示用户可手动填写或重试。
- 素材加载失败：显示错误，但无素材流程仍可用。
- 素材解析内容为空：仍将标题、来源和备注交给简报模型；如果所有已选素材均无有效信息且没有想法，返回 400。
- 正文生成失败：保留写作简报和素材选择，允许直接重试，不返回空白页。
- 正文请求超时：继续使用现有轮询恢复；服务端生成标题必须遵循 `title_hint`。
- 重复点击：简报和正文按钮在各自请求期间禁用，避免重复调用。

## 成本与范围

- 写作简报增加一次短文本调用，单独记账并在页面显示本次实际费用。
- 正文、提示词、封面和正文配图费用保持现有记录方式。
- 不新增数据库表或迁移，不持久化尚未生成文章的简报。
- 不自动创建资料、不修改资料内容、不自动排除已使用素材。
- 不改变小红书工作区、公众号素材库、形象库和发布中心的职责边界。

## 验收标准

- 素材选择位于写作页首屏最前方。
- 选择素材并确认后自动填充标题、主题、目标读者和语气。
- 不选择素材时，输入一句话想法也能生成简报和正文。
- 未选择素材且未输入想法时，不允许调用模型。
- 自动生成的简报可编辑，来源变化不会静默覆盖人工修改。
- 原独立“生成文章”步骤被删除，正文在第一步直接生成。
- 打开已有文章仍进入正确的编辑或配图步骤。
- 简报调用进入公众号账单统计，素材归属校验保持 404 隔离。
- 简报失败、素材加载失败和正文失败均保留当前输入并可重试。
- 前端行为测试、公众号后端定向测试和生产构建通过。
