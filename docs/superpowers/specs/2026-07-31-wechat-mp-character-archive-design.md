# 公众号形象归档设计

## 目标

为公众号形象管理增加安全的删除入口。用户删除自定义形象后，该形象从形象库和新文章选择中隐藏，但历史文章、提示词、配图和已确认四视图仍保持可用。

## 范围

- 仅支持归档当前用户创建的自定义形象。
- 内置“小猫插画”和虚拟选项 `none` 不允许归档。
- 本期不提供恢复入口和物理删除。
- 不删除四视图数据库记录或本地图片文件。

## 数据模型

在 `wechat_mp_illustration_characters` 增加可空字段 `archived_at`。

- `NULL`：正常可用。
- 非空：已归档，不向形象管理页和新文章选择器返回。

归档不改变 `status`、`anchor_version` 或四视图确认状态，避免破坏历史文章重新渲染时使用的形象锚点。

## 后端接口

新增：

```text
DELETE /api/platforms/wechat-mp/illustration-characters/{character_id}
```

行为：

- 仅能操作当前用户拥有的形象。
- 找不到或不属于当前用户时返回 `404`。
- 内置形象返回 `400`。
- 成功后设置 `archived_at`，返回 `204` 且无响应体。
- 重复归档按不可见资源处理，返回 `404`。

形象列表默认排除 `archived_at IS NOT NULL`。历史解析函数仍可按文章保存的 `skill_name` 或 `character_id` 解析归档形象，保证已有文章和配图流程不失效。

## 前端交互

- 自定义形象卡片增加危险样式“删除”按钮。
- 点击后显示二次确认，说明“删除后不再出现在形象库，但历史文章仍保留”。
- 删除期间仅对应卡片进入 loading。
- 成功后从当前列表移除并显示成功提示。
- 内置形象不展示删除按钮。
- 请求失败时保留卡片并展示后端错误。

## 测试

后端覆盖：

- 当前用户可以归档自定义形象。
- 归档后形象不再出现在列表。
- 四视图记录和文件引用不被删除。
- 归档形象仍能被历史解析函数解析。
- 内置形象不能归档。
- 不能归档其他用户的形象。

前端覆盖：

- API 客户端发送正确的 `DELETE` 请求。
- 自定义形象展示删除入口，内置形象不展示。
- 删除成功后刷新或更新列表。

## 非目标

- 永久删除数据库记录和图片文件。
- 回收站、批量归档或恢复。
- 自动修改历史文章的 `illustration_skill`。
